## 3.1.3 주요 기능

ScenePlus ai는 **TubeWorker 프로젝트의 대본·자막을 읽고, 필요한 씬을 배경 + 움직이는 누끼 + 타이포·차트 클립으로 만들어 해당 씬에 올리는 Chrome 확장과 로컬 제작 엔진**입니다.
기존 도입부 제작에 더해 전체·부분 씬 설계, Flow 사진 배경, 그림체·색상·연출 선택을 제공합니다.

| 기능 | 할 수 있는 일 |
| --- | --- |
| **도입부·전체·부분 AI 설계** | 도입부 추천뿐 아니라 전체 씬, 파트 복수 선택, 시작~끝 씬 번호 범위를 설계합니다. 설계 후 실제 제작할 씬은 따로 선택합니다. |
| **Flow 이미지를 씬 배경으로 사용** | 다른 도구에서 만든 Flow 씬 이미지를 원본 씬 번호에 연결합니다. 새 다운로드를 연결하거나, 이미 받은 `01_01.jpg` 같은 이미지를 선택해 가져올 수 있습니다. |
| **로컬 로고 정리와 배경 움직임** | 연결한 Flow 이미지의 저장된 우측 하단 로고 영역을 번들 ONNX/WASM 모델로 정리하고 약한 블러·확대·이동을 적용합니다. 원본과 정리본은 구분해 보관하며, 이 처리에 Python 설치나 실행 시 모델 다운로드는 필요하지 않습니다. |
| **누끼·문구·차트 모션 합성** | 전체 화면 배경 위에 움직이는 누끼, 짧은 타이포, 근거 있는 숫자 그래픽을 합성합니다. 차트 수치는 원본 대본의 근거를 사용하며, 원본 음성·SRT를 편집하지 않습니다. |
| **누끼 그림체 8종** | 웹툰, 수채화, 종이 콜라주, 플랫 벡터, 시네마틱 3D, 지점토 클레이, 실사, 픽셀 아트 중 고릅니다. |
| **타이포 색상 7종** | 클래식·옐로, 민트, 스카이 블루, 코랄, 라벤더, 로즈, 라임 조합을 미리 보고 저장합니다. 글자·강조색·강조 글자색에 적용되며 차트의 증가·감소 색은 유지합니다. |
| **씬별 연출 6종** | 누끼+문구, 무대 연출, 좌우 비교, 타임라인, 흐름도·이동 경로, 차트·비율 중 고릅니다. 차트에 쓸 수치 근거가 없으면 숫자를 만들지 않고 누끼·문구 중심으로 처리합니다. |
| **배경 방식과 AI 역할 설정** | AI가 설계하는 스톡 영상·자료사진·Grok 생성 배경과 연결한 Flow 사진 배경을 구분해 사용합니다. 도입부 계획·씬 설계·자료 검수 등 역할별 Codex/Claude CLI 모델도 설정할 수 있습니다. |
| **완성 클립 선택 업로드** | 제작 후 미리 보고 **선택 N개 올리기**로 TubeWorker에 업로드합니다. Flow 제작 결과는 번호별 MP4를 한 폴더에 모아 **완성 클립 폴더 열기**로도 확인할 수 있습니다. |
| **실패 구분과 재시도** | 다운로드 연결, 로고 정리, 씬 제작의 실패를 구분해 확인하고 해당 작업을 다시 시도합니다. 새 제작 배치에서는 기존 성공 파일을 덮어쓰지 않으며, 장면 구성을 수정해도 누끼 이미지가 다른 대상으로 바뀌지 않도록 연결을 보존합니다. |

**그림체·색상 설정 위치:** 확장 설정의 **클립 그림체·색상**에서 미리 보고 저장합니다.
저장한 선택은 새 설계·제작 요청부터 적용되며 기존 완성 클립을 자동으로 바꾸지 않습니다. 미리보기는 스타일 예시이고 실제 생성 결과는 달라질 수 있습니다.

**Flow 사진 제작의 출력:** 원래 씬 길이의 master와 업로드용 **1920×1080 · 30fps · 무음 MP4**를 따로 보관합니다.
업로드본은 필요할 때 전체 내용을 배속 조절해 **5~12초** 범위로 맞추며, 끝부분을 잘라 길이를 맞추지 않습니다.

### 사용 흐름

1. TubeWorker의 프로젝트 이미지·동영상 단계에서 **ScenePlus ai**를 엽니다.
2. **AI 설계 범위**에서 도입부 / 전체 씬 / 파트 선택 / 씬 번호 범위를 고르고 설계합니다.
3. **배경 제작 방식**을 선택합니다. Flow 사진을 쓸 때는 사용할 Flow 프로젝트를 열고 **새 Flow 다운로드 연결**을 누르거나, 이미 받은 씬 이미지를 선택해 **선택 이미지 연결**로 가져옵니다. 이 경로는 외부 도구의 이미지 생성·다운로드를 받아 쓰는 기능입니다.
4. 설계를 확인하고 제작할 씬과 씬별 배경·연출을 선택해 제작합니다.
5. 완성 클립을 확인한 뒤 **선택 N개 올리기**로 업로드합니다. 실패가 있으면 표시된 원인을 확인하고 해당 작업을 재시도합니다.

위는 3.1.3에 포함된 기능 설명이며, 실제 AI·Flow·Grok 사용에는 선택한 공급자의 설치·로그인·사용 권한이 필요합니다. 이번 베타의 실기 검증 범위는 상단 **확인됨 / 미확인** 안내를 참고하세요.

## 처음 설치하기

### Windows

1. EXE를 실행해 설치합니다.
2. 처음 설치하는 경우에만 **Fresh install**을 선택합니다.
3. 시작 메뉴의 **Open extension folder**로 확장 폴더를 확인합니다.
4. **Engine status**에서 실행 상태와 받은 설치판의 버전을 확인합니다. 베타는 `3.1.3`입니다.

### Mac

1. PKG를 설치한 뒤 응용 프로그램의 **ScenePlus ai**를 엽니다.
2. 엔진 설치를 진행하고, 처음 설치하는 경우에만 **Fresh install**을 선택합니다.
3. 앱의 **Open extension folder**로 확장 폴더를 확인합니다.

서명되지 않은 PKG가 차단되면 파일 출처를 확인한 뒤 시스템 설정 →
개인정보 보호 및 보안에서 해당 파일의 **그래도 열기**로 진행합니다.

### Chrome 확장 연결

1. 신규 설치는 `chrome://extensions`에서 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램 로드**로 위에서 확인한 확장 폴더를 등록합니다. 기존 확장이 있으면 삭제하지 말고 새로고침합니다.
3. TubeWorker 탭을 새로고침하고 엔진과 확장이 같은 버전으로 연결되는지 확인합니다. **베타는 3.1.3, 기존 안정판은 2.8.30**입니다.

## AutoPlus에서 ScenePlus ai까지

처음 목표는 자막과 음성을 바탕으로 영상 한 편을 만드는 것이었습니다.
AutoPlus 앱에서 장면을 설계하고, 배경 영상과 배경을 제거한 이미지,
그래프와 타이포그래픽을 조합하며 제작 흐름을 다듬었습니다.
작업을 반복하면서 방향도 바뀌었습니다.
완성 영상 전체를 새로 만드는 대신, 이미 TubeWorker에서 만들고 있는 영상에
필요한 장면을 보태는 편이 실제 사용 흐름에 더 잘 맞았습니다.

그 전환에서 ScenePlus ai가 시작됐습니다.

### 한 편을 만드는 앱에서, 필요한 장면을 만드는 도구로

2026년 10월 19일부터 중심을 Chrome 확장 프로그램과 로컬 엔진으로 옮겼습니다.
TubeWorker에서 장면을 선택하고, 그 내용에 맞는 배경과 누끼 이미지,
모션그래픽을 만들어 넣는 방식입니다.

개인용 제작에서는 GPT Image 등의 이미지 생성과 Grok 배경 영상을 활용하면서
누끼·타이포의 연출, 등장 타이밍, 배경의 역할을 조정했습니다.
단순히 소재를 구하는 것뿐 아니라, 장면의 내용과 시각적 강조가 맞도록
실제 결과물을 보고 수정하는 과정이 이어졌습니다.

### 다른 사용자도 쓸 수 있도록 Google Flow 추가

개인 환경에 맞춘 도구를 다른 사람에게 나누려면 이미지 생성 선택지와 연결 과정도 필요했습니다.
10월 30일에는 Google Flow 이미지 생성을 추가하기 시작했습니다.
이미지를 한 장씩 순서대로 만들고, 설정과 입력 대상을 확인한 뒤,
생성 결과를 회수해 장면 제작으로 이어지는 흐름을 구현했습니다.

첫 성공 확인은 **11월 2일 낮 12시 9분**, 추가 요청으로부터 **약 65시간 10분 뒤**였습니다.
이후에도 연결 순서, 실패 안내, 재연결과 TubeWorker로 돌아오는 흐름을 수정했습니다.
Flow 추가부터 후속 안정화 구간까지의 경과 시간은 **약 86시간 48분**입니다.
이는 대기와 휴식을 포함한 기간이지, 연속 작업시간이나 이미지 한 장의 생성시간은 아닙니다.

### 실행되는 도구에서, 설치하고 업데이트할 수 있는 배포판으로

마지막 단계에서는 원본 소스의 직접 노출을 줄이는 보호 빌드와
Windows EXE·Mac PKG 설치 파일을 준비했습니다.
업데이트 파일의 서명·무결성 확인, 작업 중 업데이트 차단,
사용자 데이터 보존과 실패 복구, 기존 엔진·확장 연결 보안도 함께 확인했습니다.
설치·연결과 업데이트 확인을 거쳐 2.8.30 설치판을 배포 저장소에 게시했습니다.

현재 설치판에는 **Windows 코드서명과 macOS Developer ID 서명·공증이 없습니다.**
업데이트 파일을 검증하는 내부 서명과 운영체제의 배포자 서명은 서로 다른 항목입니다.
설치 방법과 지원하는 업데이트 범위는 위의 [처음 설치하기](#처음-설치하기)와
[기존 보호판 업데이트](#기존-보호판-업데이트)를 참고하세요.

### 숫자가 의미하는 것

- **경과 시간**에는 대기·휴식이 포함됩니다. 실제 노동시간이나 AI의 전체 연산시간을 측정한 값은 아닙니다.
- **캐시 포함 토큰**에는 기존 대화와 코드를 다시 읽는 캐시 처리가 포함됩니다.
  전부 새로 작성한 코드나 답변의 분량은 아닙니다.
- **캐시 제외 입력·출력**은 캐시 읽기·쓰기를 제외해 따로 합한 값입니다.
  이것도 출력 토큰만을 뜻하지는 않습니다.
- 실패·재시도·재작업과 같은 기간의 병행 수정이 포함됩니다.
  특정 기능 하나의 독립적인 개발 원가로 해석할 수 없습니다.
- 일부 손상된 기록이나 별도 실행이 누락됐을 가능성이 있어 완전한 사용량 청구서 수준의 확정값은 아닙니다.
- 이미지·영상 생성 크레딧, 구독료와 실제 지출액은 이 집계에 포함하지 않았습니다.
  개발 토큰을 사용자 한 명의 이용 비용으로 환산할 수도 없습니다.

앱 이전인 9월 18일부터의 영상 제작·자동화 실험까지 범위를 넓히면
경과 기간은 **약 47일**, 캐시 포함 토큰은 **약 32.44억**입니다.
이는 위 합계에 선행 실험을 포함한 별도 범위이며, 두 수치를 더하지 않습니다.

ScenePlus ai는 이처럼 개인 제작 실험에서 출발해, 필요한 장면을 만드는 도구를 거쳐,
다른 사용자에게 설치 파일로 전달할 수 있는 형태로 발전했습니다.
