# AutoPlus에서 ScenePlus ai까지

처음 목표는 자막과 음성을 바탕으로 영상 한 편을 만드는 것이었습니다.
AutoPlus 앱에서 장면을 설계하고, 배경 영상과 배경을 제거한 이미지,
그래프와 타이포그래픽을 조합하며 제작 흐름을 다듬었습니다.
작업을 반복하면서 방향도 바뀌었습니다.
완성 영상 전체를 새로 만드는 대신, 이미 TubeWorker에서 만들고 있는 영상에
필요한 장면을 보태는 편이 실제 사용 흐름에 더 잘 맞았습니다.

그 전환에서 ScenePlus ai가 시작됐습니다.

## 한 편을 만드는 앱에서, 필요한 장면을 만드는 도구로

2026년 10월 19일부터 중심을 Chrome 확장 프로그램과 로컬 엔진으로 옮겼습니다.
TubeWorker에서 장면을 선택하고, 그 내용에 맞는 배경과 누끼 이미지,
모션그래픽을 만들어 넣는 방식입니다.

개인용 제작에서는 GPT Image 등의 이미지 생성과 Grok 배경 영상을 활용하면서
누끼·타이포의 연출, 등장 타이밍, 배경의 역할을 조정했습니다.
단순히 소재를 구하는 것뿐 아니라, 장면의 내용과 시각적 강조가 맞도록
실제 결과물을 보고 수정하는 과정이 이어졌습니다.

## 다른 사용자도 쓸 수 있도록 Google Flow 추가

개인 환경에 맞춘 도구를 다른 사람에게 나누려면 이미지 생성 선택지와 연결 과정도 필요했습니다.
10월 30일에는 Google Flow 이미지 생성을 추가하기 시작했습니다.
이미지를 한 장씩 순서대로 만들고, 설정과 입력 대상을 확인한 뒤,
생성 결과를 회수해 장면 제작으로 이어지는 흐름을 구현했습니다.

첫 성공 확인은 **11월 2일 낮 12시 9분**, 추가 요청으로부터 **약 65시간 10분 뒤**였습니다.
이후에도 연결 순서, 실패 안내, 재연결과 TubeWorker로 돌아오는 흐름을 수정했습니다.
Flow 추가부터 후속 안정화 구간까지의 경과 시간은 **약 86시간 48분**입니다.
이는 대기와 휴식을 포함한 기간이지, 연속 작업시간이나 이미지 한 장의 생성시간은 아닙니다.

## 실행되는 도구에서, 설치하고 업데이트할 수 있는 배포판으로

마지막 단계에서는 원본 소스의 직접 노출을 줄이는 보호 빌드와
Windows EXE·Mac PKG 설치 파일을 준비했습니다.
업데이트 파일의 서명·무결성 확인, 작업 중 업데이트 차단,
사용자 데이터 보존과 실패 복구, 기존 엔진·확장 연결 보안도 함께 확인했습니다.
설치·연결과 업데이트 확인을 거쳐 2.8.30 설치판을 배포 저장소에 게시했습니다.

현재 설치판에는 **Windows 코드서명과 macOS Developer ID 서명·공증이 없습니다.**
업데이트 파일을 검증하는 내부 서명과 운영체제의 배포자 서명은 서로 다른 항목입니다.
설치 방법과 지원하는 업데이트 범위는 [다운로드 안내](../README.md)를 참고하세요.

## 단계별 시간과 토큰

관련 로컬 로그 340개를 바탕으로 중복 응답 기록을 제거한 잠정 집계입니다.
기간은 한국시간 기준이며, 단계는 작업이 진행된 시기별로 나눴습니다.

| 단계 | 기간 | 경과 시간 | 캐시 포함 토큰 | 캐시 제외 입력·출력 |
| --- | --- | ---: | ---: | ---: |
| AutoPlus 앱 개발 | 2026년 9월 27일~10월 19일 | 약 22일 | 약 9.95억 | 약 4,410만 |
| 개인용 ScenePlus ai 전환 | 10월 19일~10월 30일 | 약 11일 | 약 14.44억 | 약 2,159만 |
| Google Flow 추가·안정화 | 10월 30일~11월 3일 | 약 3일 15시간 | 약 3.78억 | 약 638만 |
| 보호 빌드·설치·배포 | 11월 3일~11월 4일 | 약 15시간 34분 | 약 1.53억 | 약 297만 |
| **합계** | **9월 27일~11월 4일** | **약 38일** | **약 29.69억** | **약 7,504만** |

집계 마감은 로그 타임스탬프 기준 **2026년 11월 4일 오전 1시 22분(KST)**입니다.
표시값은 반올림했으므로 각 행의 표시값을 더한 수치와 합계에 차이가 날 수 있습니다.

### 숫자가 의미하는 것

- **경과 시간**에는 대기·휴식이 포함됩니다. 실제 노동시간이나 AI의 전체 연산시간을 측정한 값은 아닙니다.
- **캐시 포함 토큰**에는 기존 대화와 코드를 다시 읽는 캐시 처리가 포함됩니다.
  전부 새로 작성한 코드나 답변의 분량은 아닙니다.
- **캐시 제외 입력·출력**은 캐시 읽기·쓰기를 제외해 따로 합한 값입니다.
  이것도 출력 토큰만을 뜻하지는 않습니다.
- 실패·재시도·재작업과 같은 기간의 병행 수정이 포함됩니다.
  특정 기능 하나의 독립적인 개발 원가로 해석할 수 없습니다.
- 일부 손상된 기록이나 별도 실행이 누락됐을 가능성이 있어 완전한 사용량 청구서 수준의 확정값은 아닙니다.
- 이미지·영상 생성 크레딧, 구독료와 실제 지출액은 이 집계에 포함하지 않았습니다.
  개발 토큰을 사용자 한 명의 이용 비용으로 환산할 수도 없습니다.

앱 이전인 9월 18일부터의 영상 제작·자동화 실험까지 범위를 넓히면
경과 기간은 **약 47일**, 캐시 포함 토큰은 **약 32.44억**입니다.
이는 위 합계에 선행 실험을 포함한 별도 범위이며, 두 수치를 더하지 않습니다.

ScenePlus ai는 이처럼 개인 제작 실험에서 출발해, 필요한 장면을 만드는 도구를 거쳐,
다른 사용자에게 설치 파일로 전달할 수 있는 형태로 발전했습니다.
